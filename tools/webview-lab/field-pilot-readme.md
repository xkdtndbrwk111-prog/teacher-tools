# HOJA WebView2 Field Pilot A1 (1.66.43 기반)

**정식 운영판 아님. 별도 시험 데이터만 사용합니다.** Windows x64, Microsoft Edge WebView2 Runtime 및 .NET Framework 4.x가 필요합니다. 관리자 권한, 자동 시작, 운영 업데이트 피드 변경을 요구하지 않습니다.

압축을 완전히 푼 다음 일반 Windows PowerShell에서 파일이 있는 폴더로 이동합니다.

```powershell
.\Start-Pilot.ps1
```

- 시험판 프로그램·프로필·데이터 위치: 현재 사용자의 LocalAppData 아래 TeacherToolsWebView2Pilot.
- 현재 운영 호자보드의 TeacherToolsLocal/TeacherToolsMedia 및 Chrome 프로필은 읽거나 이전하지 않습니다.
- 시험판 전용 포트 17451이 이미 사용 중이면 다른 프로세스를 종료하지 않고 중단합니다.
- 창 닫기 후 시험판 소유 서버만 종료합니다.
- 바탕화면 방식은 `-Mode wallpaper`로 별도 시험합니다.
- 아몬드 실제 Canva 연결은 `-LiveBook`으로 명시적으로 시작합니다. 원본 책 재생기와 별도 시험 프로필을 사용합니다. 계정 로그인은 사용자가 직접 합니다.
- 다운로드 권한을 가진 영상만 `-LiveDownload`로 시험합니다. 원본 엔진 다운로드가 발생할 수 있습니다.
- 실제 외부 프레임(회의 Canva·YouTube, 온라인 미니게임 등)은 아직 허용 범위가 검토되지 않아 차단됩니다. 스피커 변경 등 일부 시스템 쓰기도 비활성입니다. 실제 운영 교실 데이터로 시험하지 마세요.
- 파일 해시는 로컬 손상 검사용이며 코드 서명을 대체하지 않습니다. 서명되지 않은 실행 파일에 Windows 보안 경고가 나올 수 있습니다. 보안 기능을 끄지 마세요.

## A1 시험 순서

1. 창 모드 실행·종료 후 다시 실행하여 메모 유지 확인.
2. 바탕화면 모드의 모니터 위치 및 터치 확인.
3. 오프라인 보관함 파일 재생.
4. 별도 실행에서 실제 책 읽어주기와 페이지 이동·북마크.
5. 허가된 영상의 실제 다운로드/취소.

A1은 수동 설치 후보이며 자동 업데이트 연결과 실제 외부 프레임·운영 데이터 이전은 다음 단계에서 검증합니다.
