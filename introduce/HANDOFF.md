## 만든 파일

| 파일 | 역할 |
|---|---|
| `introduce/index.html` | 페이지 골격(내비·첫 화면·지도·제품 영역·상세 다이얼로그). 내용은 JS가 데이터로 채움 |
| `introduce/data.js` | **유일한 데이터 원본**. `PRODUCTS`(고정 순서·색·실행 링크·미디어), `NODES`(ID·좌표·크기·설명), `EDGES`(연동선·방향·종류), `ONE_MORE` |
| `introduce/introduce.css` | 디자인(크림/브랜드 녹색, 제품별 강조색, 반응형, reduced-motion) |
| `introduce/introduce.js` | 지도 렌더링·카메라·상세·라우팅·첫 화면 연출 |
| `index.html`, `hub.css` | 공작소 메인 헤더에 “도구 전시관 둘러보기 →” 링크 추가 |

노드 추가: `data.js`의 `NODES`에 객체 1개 추가 → 지도·상세·제품 영역에 자동 반영.
좌표: `grid.col`(제품 열 0–4), `grid.row`(0 = 대표 노드), `grid.x`(-1 왼쪽 가장자리 / 0 / 1 오른쪽 가장자리).
연동선: `EDGES`의 `from → to` = 데이터 흐름 방향. `kind`가 다르면 별도의 선으로 그린다.

## 완성된 기능 (1·2·3차 범위 대부분)

- 상단 얇은 내비(홈 + 5개 제품, 활성 밑줄, 모바일 가로 스크롤, 공작소 홈 링크)
- 5열 기능 지도: 제품 영역, 대표 노드(크게), 기능 노드, 연동 포트
- 연동선 4개: 코인(호자보드→미니게임), 명단·자리표(교실매니저→호자보드), 테마(호자보드가 교실매니저 테마를 가져옴, 점선·별도 선), 명단(교실매니저→한자매니저). 호자게임은 연동선 없는 독립 영역
- 연결선 표시 hover/focus 시 양쪽 노드 발광, 클릭 시 카메라가 반대편 노드로 이동
- 카메라: 드래그 이동, Ctrl/⌘+휠·트랙패드·터치 핀치 확대(일반 휠은 페이지 스크롤 유지), +/−/전체 보기, 제품 칩, 키보드(방향키·+/−·0·Esc)
- 확대 수준 3단계(far/mid/near): far에서는 기능 글자·배지 숨기고 선 굵게
- 기능 상세: 노드 위치에서 펼쳐지는 패널, 같은 제품 기능 좌우 넘김(스와이프·버튼·방향키), 연결 기능 이동(상세 닫기 → 카메라 이동 → 도착 노드 열기), 실행 버튼(호자보드는 “정식판 준비 중” 비활성, 링크 없음)
- 해시 라우팅: `#/`, `#/map`, `#/product/{id}`, `#/node/{nodeId}` — 새로고침 없음, 뒤로 가기·직접 링크 동작
- 첫 화면: 연동 4개 프로그램이 타원 궤도로 순환(앞쪽 크게·밝게), 호자게임은 궤도 밖 독립 카드, 스크롤에 따라 궤도가 멈추며 5열로 정렬(역스크롤 시 역방향)
- 제품별 스크롤텔링 영역(대표 화면 확대, 기능 카드 순차 등장) + One More Thing(미니게임·호자보드·교실매니저, 실제 연동만)
- 영상 지연 로딩(IntersectionObserver), `prefers-reduced-motion` 대응

## 시험 결과 (로컬 정적 서버 + 앱 내장 브라우저, 수동)

- 데스크톱(약 800×600 창): 첫 화면 궤도, 지도 전체 보기, 교실매니저 확대·연동선, `#/node/class.roster` 상세 — 정상, 콘솔 오류 없음

## 확인 필요 / 미완료 (우선순위 순)

1. **기능 문구 사실 확인**: 노드 설명은 작업 지시서 기준으로 작성했고 각 프로그램 최신 소스(hoja-minigames, 호자보드 런타임, SMQ-Project-A)와 대조하지 못함. 특히 미니게임 장르 구성(실제 화면엔 오셀로·오목·호자배구·틱택토 등이 보임), 호자보드 수업 보조 도구·멀티미디어 세부, 코인 연동 방향(현재 호자보드→미니게임으로 표시), 호자게임의 오답 복습·랭킹이 운영판에 있는지
2. 기능별 실제 화면: 현재 모든 노드가 제품 대표 화면(hub 카드 이미지·영상)을 “대표 화면” 캡션과 함께 재사용. 기능별 캡처(학생 개인정보 제외)를 `node.media`에 추가하면 자동 적용
3. 교실매니저 미리보기 영상에 학생 이름처럼 보이는 텍스트가 있음 — 기존 허브 자산 재사용이며 샘플 이름인지 확인 필요
4. 4차: 브라우저 교차 검사, 성능 측정, 기존 공작소 회귀(tests/README.md 절차), PR 작성·CI 확인 후 승인된 경우에만 병합
5. 디자인 고도화: far 줌에서 제품 간 요약 연결만 남기는 간소화, 지도 진입 시 첫 화면 카드가 지도 열로 이어지는 연결 연출
