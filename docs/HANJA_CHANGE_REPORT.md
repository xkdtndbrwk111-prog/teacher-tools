## 남은 범위 및 리스크

- 실제 공개 배포, Safari/Firefox, 실기기 터치, 실제 한국어 IME 조작과 스피커 청취는 미검증. 효과음 호출과 UI 동작은 검증했고 음질/기기별 출력은 확인 필요.
- 자리배치 모든 규칙 조합과 전체 1x 애니메이션을 재전수검사하지는 않음. 해당 로직 변경 없음.
- 명단은 동일 origin에서 자리배치가 저장한 데이터만 사용. 다른 도메인의 기존 명단은 자동 이동하지 않음.
- 한자 데이터는 브라우저 로컬 저장. 서버 동기화·백업 내보내기는 이번 범위에 없음.
- 새로고침하면 진행 중 수업과 참가/제외는 초기화. 데이터와 문제 설정은 유지.
- 객관식 고유 답이 부족하면 보기 수 축소, 2개 미만이면 수동 전환/데이터 추가 안내.
- 이전 ChatGPT 프로토타입 파일 대신 실제 main V6.24 코드와 자산을 기준으로 구현.
