## 기술적 한계 (현장 검증 전에는 PASS 금지)
- Canva 직접 창은 보안상 별도 출처이며 호자보드가 창 내부의 **실제 페이지 번호를 자동으로 알 수 없다.** 페이지 입력은 교사가 직접 수정하며 수정 시 저장한다.
- 호자보드 '전체화면'은 **호자보드 모달**의 전체화면이다. 별도 Canva 브라우저 창의 전체화면은 해당 브라우저에서 F11(또는 Canva의 발표 전체화면)으로 조작한다. 보안 제약으로 호자보드 버튼이 다른 출처의 창을 강제로 전체화면으로 만들 수는 없다.
- 팝업이 브라우저 설정으로 차단된 경우 제목 링크를 클릭하면 다시 열 수 있다.
- 실기기에서 Canva의 클릭 애니메이션 자체와 재생 안정성은 수동으로 확인해야 한다.
